# MekaPlan

Minecraft 1.20.1 / Forge向け。Just Enough Mekanism Multiblocks（JEMM）の既存EMIページに、
GT風のLDLib製3Dプレビューと、Litematica風の建築用ホログラムを追加します。
設備は「Mekanism マルチブロック設備」の1カテゴリーに集約し、ページで切り替えます。
左に模型、右にJEMMの設定・性能を並べ、プレビューを閉じずに編集できます。
右端は「性能」を初期表示し、必要なときだけ「素材」に切り替えられます。

## 設計データ

寸法・ガラス・ポート数・内部部品・核分裂炉の高度な燃料棒配置・性能計算はJEMMが管理します。
本ModはJEMM 4.27の生成したブロック状態と必要素材を直接取得し、別の計算式で置き換えません。
投影開始時の設計を固定するため、その後JEMMを編集しても設置中のガイドは変わりません。

基本8設備（ダイナミックタンク、熱蒸発プラント、インダクションマトリックス、熱電ボイラー、
SPS、核分裂炉、核融合炉、工業用タービン）を対象に動作確認します。
Generators由来の設備にはMekanism: Generatorsが必要です。
JEMMがプレビューを提供する追加設備も共通経路で扱います。検証済みの追加Modは下記を参照してください。
配管・外部熱源・燃料供給設備などは、JEMMのプレビューに含まれる範囲に従います。
すべてのパラメーターで設備の成立や最適性能を保証するものではありません。

## 導入

mekaplan-forge-1.20.1-0.1.0-alpha.8.jarをクライアントのmodsへ追加します。
旧名「Mekanism: Structure Preview」から表示名・配布ファイル名を変更しています。内部Mod IDのmekpreviewは維持しています。
旧alpha版と重複させないでください。表示・投影だけならサーバー導入は不要です。
右クリック設置を使う場合はサーバーにも同じJARを追加します。
alpha.8はNBT付き素材の保護をサーバーでも保証するため設置通信のバージョンを更新しています。
サーバーに旧alpha版がある場合は両側をalpha.8へそろえてください。本Mod未導入のサーバーへの接続は引き続き可能です。
本Modのサーバー側前提はForgeだけです。JEMM・LDLib・EMI・TMRVはサーバーに必要ありません。
設置したいブロックを提供するMekanism等は、当然サーバー側にも導入されている必要があります。

| 依存Mod | 検証バージョン |
|---|---|
| Forge | 47.4.18 |
| Mekanism | 10.4.16.80 |
| LDLib | 1.0.50 |
| EMI | 1.1.24 |
| Just Enough Mekanism Multiblocks | 4.27（4.18は非対応） |
| TooManyRecipeViewers（JEI代替） | 0.9.0+mc.20.1 |
| Mekanism: Generators（任意） | 10.4.16.80 |

TMRVでJEI APIを提供する構成に対応しています。JEI本体とTMRVは同時導入しないでください。
JEI本体15.20.0.132を使う従来の構成も利用できます。
JEMM 4.18には必要な構造取得APIがないため、4.27が必要です。
ビルド・検証は既存サーバーやPrismのmodsを自動更新しません。
依存Modのサーバー導入要件や配布条件はそれぞれのModに従ってください。
シェーダー環境、構造ルールを変更するMod、他のJEMMバージョンは未検証です。

## 任意アドオン連携

- Nova Mekanism 1.2.2：Mod自身の建築用ブループリントとレシピ・性能計算を読み込みます。固定構造なので寸法は変更しません。
- More Thermal Evaporation 3.1.0：5ティアのJEMM設定・費用を使います。大型はMod自身の検証用グリッドから配置を取得します。
- Mekanism Extras 1.5.0：JEMMが提供する追加設備を統合対象にします。
- More Thermal Evaporation Compat：任意の連携処理を用意していますが、2.3-fix1本体の任意依存不具合により実機検証は保留です。

これらのアドオンは本Modの必須前提ではありません。未導入なら読み込みません。
未対応のNova APIでは、そのレシピの元の表示を残して警告を記録します。
他のアドオンすべてを自動解析できるものではありません。

## 使い方

1. Kキー、またはEMIの「Mekanism マルチブロック設備」を開きます。
2. 右の寸法・部品数を変更すると、左の模型・必要素材・性能がリアルタイムに更新されます。
3. 模型をドラッグ回転、ホイール拡大縮小。模型右端で層・表示モード・外装・90度回転を選びます。
4. 「ホログラムを投影」で現在の設計をワールドに表示します。

右下の「検索」「不足」「★」で、模型を残したまま検索・素材・保存パネルを開きます。同じボタンで設定・性能欄に戻ります。

### Novaのレシピ検索・EMI連動

「検索」はレシピ名、入力・出力名、レジストリIDを対象にします。空白区切りの複数語、英字の大小、全角英数に対応します。
検索結果をクリックすると対応する元のレシピ番号を選択し、模型・性能が更新されます。元の番号スライダーも残します。
Novaの加工レシピには「設備プレビュー」を追加します。選択したレシピを設備側へ引き継いで開きます。
通常のEMI加工レシピでも、出力アイコンにカーソルを合わせて設備一覧キー（初期K）を押すと、対応するNova設備があれば連動します。
照合は元のレシピ本体またはIDで行い、出力名だけで推測しません。EMIの検索欄に入力中はキーを横取りしません。

### 不足素材

「全体」はJEMMの必要素材一覧、「表示中」は現在の層モード・外装表示に含まれる物理ブロックを集計します。
所持数は設置支援と同じホットバー＋メインインベントリを対象とし、「残り」「所持」「不足」を表示します。
通常品を数え、NBT付きは現在手に持って明示的に使用しているスタックのみ数えます。
不足のみ／全素材を切り替えられます。長い名前や正確な個数は行のツールチップで確認できます。
非ブロック素材は全体集計にだけ含めます。インベントリや表示条件が変わったときに更新し、毎フレーム全設計を再集計しません。
同じ設計・回転の投影を固定中なら、正しく設置済みの物理ブロック数も差し引きます。
別の設備・構成・回転や、照準へ追従中の投影の設置数は流用しません。
ツールチップで必要総数・設置済み・残り・所持・不足を確認できます。
投影中は現在の表示層に必要な残りブロックをHUDへ最大5種類表示します。
非ブロック素材の装着状態、AE2・バッグ・オフハンド内は検査しません。

### ブロック選択・補充・完成通知

操作設定の「照準先の必要ブロックを選択」にキーを割り当ててください（他Modとの競合を避け、初期未割り当て）。
投影のブロックに照準を合わせて押すと、通常品をホットバーから選択、またはメインインベントリから手持ちスロットへ交換します。
交換先の道具等は元の素材スロットへ移し、削除や上書きはしません。NBT付きしかない場合は通知し、自動選択しません。
投影建築で右クリック後に手持ちが尽きたら、元のアイテムとNBTまで一致するスタックだけを同じスロットへ補充します。
持ち替え・GUI表示・設定OFFで補充予約を解除します。補充は右クリック後2秒以内が対象です。
選択・補充は通常のインベントリ通信を使い、サーバー側の本Modがなくても利用できます。
その場合の右クリックは通常設置であり、向き等はMinecraft本来の設置操作に従います。

固定した設計の全ブロックと物理的な向きが一致すると、一度だけ通知して投影を非表示にします。
単層だけの完成では発動せず、未ロード箇所も完成扱いにしません。Vキーで完成した投影も再表示できます。
これは設備の成立・稼働・内部設定・アップグレード装着を保証する判定ではありません。
config/mekpreview-client.toml の construction セクションで、autoRefill・hideCompleted・notifyCompleted・materialHudを個別に変更できます。
既定ではすべて有効です。

### 設計のお気に入り

「★」で設計名を入力し「+」を押すと保存します。名前は省略できます。保存行をクリックして読み込み、「×」で削除します。
設備・寸法・内部構成・アップグレード・Novaのレシピ・表示層・回転・外装表示を保存し、別設備からも呼び出せます。
保存場所はクライアントのconfig/mekpreview/favorites.jsonです。ワールドやサーバーには保存しません。最大128件です。
書き込みは一時ファイルから置き換え、直前の内容をfavorites.json.bakに残します。壊れたファイルや未知の保存形式は上書きしません。
未導入の設備も保存行を残します。Novaのレシピは番号に加え安定キーで照合し、変更・削除で見つからない場合は通知します。

性能表示はJEMMおよび対応アドオン自身の計算結果をそのまま使います。
タービンの最大発電量・蒸気流量、核分裂炉の最大燃焼率、蒸発設備の最大速度などを確認できます。
最大値や必要温度などの条件・警告・単位も元の表示に従います。実際の稼働量を測定する機能ではありません。
蒸発設備の速度倍率を特定レシピのmB/tへ変換する機能はありません。
Novaではレシピ、速度／省エネアップグレード、対応設備のコイル、並列プロセッサー段階を変更できます。
処理時間・消費電力／発電量・アイテム／流体／ガスの毎秒生産量を表示します。
コイルとプロセッサーの変更は模型・必要素材・投影にも反映します。アップグレードやモジュールの装着は手動です。
性能計算にはワールドに接続しないNova本体のコントローラーを使い、実際のワールドやレシピを変更しません。
発電機と虚空採掘機はNova本体の専用処理・設定値を参照します。確率生産には「*」を付け、期待値を表示します。
並列数はプロセッサーの上限だけでなく、入出力スロットに収まるバッチ数でも制限します。
必要モジュール・マナ・入力材料は性能欄やツールチップで確認できます。
該当アドオン未導入などでNovaがレシピを登録しない設備には「対応レシピなし」と表示します。
電力／出力容量を超える条件では推測の生産量を出さず、内部容量不足を表示します。

静的な模型と投影ブロックはGPUバッファへキャッシュします。層表示の切り替えで設計自体を再取得せず、
性能条件だけの変更で模型が変わらない場合も描画キャッシュを維持します。
層変更時の投影用ブロックエンティティ再生成を省き、照準判定は全ブロック走査ではなくレイ上のセルだけ調べます。
模型のキャッシュは画面終了時、投影のキャッシュは解除・ワールド退出時に解放し、リソース再読み込みでも更新します。

通常ブロックは本来のテクスチャ付き半透明表示で、青い輪郭線は付けません。
設置済みの正しいブロックは隠し、誤ったブロックを赤で示します。
照準先には必要なブロック名・アイコン・座標を表示します。

| 初期キー | 操作 |
|---|---|
| K | JEMM設備ページ |
| G | 投影位置の固定／照準追従 |
| V | 表示切替 |
| R | 90度回転 |
| H | 不透明度25%／55%／85% |
| 矢印 | 東西南北へ移動 |
| Page Up / Page Down | 上下移動 |
| [ / ] | 表示層の移動 |
| \ | 全層／単層／指定層まで |

消去キーは初期未割り当てです。操作設定から変更できます。
投影自体は描画のみです。サーバー側にも本Modがある場合、投影ブロックを照準に入れて
右クリックで1ブロック、Shift＋右クリックで表示中のブロックを一括設置できます。
サバイバルでは実際のインベントリ素材を消費し、クリエイティブでは消費しません。
設置範囲はプレイヤーから32ブロック以内。一括処理は1tick最大16ブロック、1回最大8192ブロックです。
既存の固体ブロックやブロックエンティティは上書きしません。素材不足・距離外・保護による拒否はスキップします。
通常品を優先し、NBT付き素材は対象アイテムを実際に手に持っている場合だけ使用します。
通常のアイテム設置とForgeの設置イベントを通し、拒否された設置では素材を消費しません。
サーバー側が未導入なら理由を表示し、通常の投影機能はそのまま使えます。
アップグレードなどの非ブロック素材の装着や、完成後の機械設定は自動では行いません。
進捗はブロック種と物理的な向きを約0.5秒ごとに比較します。
空洞の障害物・外部配管・入出力設定・完成設備の性能は判定しません。
退出・ディメンション移動で投影を解除します。Litematicaとのファイル互換はありません。

## ビルドと検証

Java 17を使用します。Gradleの起動にはJava 21も使用できます。
通常ビルドはModrinth Maven / Curse Mavenから固定バージョンを取得します。
prepare-deps.ps1でSHA-256確認済みローカルコピーを使う場合は-PlocalDepsを指定します。
依存Modは成果物に同梱しません。

    .\gradlew.bat build projectZip
    .\gradlew.bat runClient -PvisualSmoke
    .\gradlew.bat runGameTestServer -PserverOnly

ローカル依存の場合、TMRVの実行にはdeps/tmrv-forge-1.20.1-0.9.0.jarが必要です。
既定の開発実行はTMRVです。JEI構成を試す場合だけ-IncludeJeiでJEIを準備し、-Pjeiで起動します。
公式配布のtoomanyrecipeviewers-0.9.0+mc.20.1.jarをその名前でコピーしてください。
SHA-256: 6B303725304189CA2A57DF34727C43E4960EE3758AD88C1B0C0486A3775754E7
JEI本体はTMRV構成の実行時には含まれません。
クライアント検証は専用run/saves/MekPreviewTMRVQA（JEI構成ではMekPreviewQA）を使います。
実際のEMIページ・JEMM入力・8設備のブロック状態／素材一致・独自燃料棒配置・層別表示・投影を検証します。
アドオン構成ではNovaの32設備・登録レシピの性能・アップグレード・コイル・並列部品も検査します。
検索・元レシピとの連動・所持数増減・表示層別の不足数・保存データの再読込・別設備からの復元も検査します。
通常の持ち替え／スロット交換通信、自動補充のNBT一致、設置済み分の減算、誤配置・方向違い、全体完成時だけの通知と非表示も検査します。
層表示での設計再取得の省略、GPUキャッシュ利用、変化しない投影のキャッシュ再利用も確認します。
結果はrun/visual-result.txt、画像はrun/screenshotsです。
単体テストは座標・層・素材の扱いを検証します。旧独立版の配置生成器はテスト専用で製品JARに入りません。
runGameTestServerの24ケースは旧配置フィクスチャの成立検査であり、JEMM設計の検証とは区別します。
-PserverOnlyはForgeと本Modだけで起動し、素材消費・NBT保持・距離・保護イベント・上書き拒否・タグ付き素材の保護など13ケースを検証します。
アドオン検証は-Paddons -PextrasでNova 1.2.2、MTE 3.1.0、Extras 1.5.0のローカルJARを使用します。
